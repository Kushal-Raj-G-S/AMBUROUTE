# research/: proof and memory for the AmbuRoute project

Everything needed to understand, defend and rebuild the work, in one place. **Start with `PROJECT_LOG.md`.**

| File / folder | What it is |
|---|---|
| `PROJECT_LOG.md` | Project memory: rules, state, key numbers, decisions, incidents, rebuild steps, open items |
| `sources.md` | Every outside source with date, extracted fact, verification status (✔ ○ ✖) and screenshot |
| `screenshots/` | Highlighted screenshots of the verified pages (proof for mam). **Local only; do not publish.** |

Conventions: ✔ opened and checked; ○ from a search summary only; ✖ blocked or could not be opened.
Dates are written out (the "29 Jul 2013" kind of mistake is the reason).

The public, polished versions of this material are in the GitHub repo under `docs/`.
